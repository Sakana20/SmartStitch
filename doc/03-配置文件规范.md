# SmartStitch 配置文件规范

## 1. 格式原则

- 使用 UTF-8 编码的 YAML。
- 配置文件允许中文路径、中文名称和中文注释。
- 路径建议使用绝对路径；环境迁移时可在前端重新选择。
- 示例中的字段名称是 schema 2 协议，开发时应通过 Pydantic 模型严格校验。
- 前端保存配置时应尽量保留注释；若所用 YAML 库不能保留注释，则保留一份人工维护的模板文件，并将界面生成配置与模板分开。

## 2. 完整注释示例

```yaml
# 配置格式版本。未来字段升级时用于自动迁移，请勿随意修改。
schema_version: 2

# 配置的唯一标识。只用小写英文、数字、短横线，创建后不建议修改。
id: taobao-xingguang

# 前端展示名称。
name: "淘宝闪购-星广"

# 是否允许在创建任务时选择此配置。
enabled: true

# 对此配置用途的说明，不参与视频生成。
description: "星广一口价 25 元素材组合"

# 路径解析根目录。旧配置可继续指向“分割后”；标准视频库指向整个库根。
source_root: "/Volumes/Elements SE/<业务素材目录>/饿了么整理/素材/星广一口价/25元/分割后"

# 成片片段顺序。利益点段使用可扩展的 benefit_<n> 名称。
# 禁用某个可选类别时，该类别会从时间线中跳过。
timeline:
  - pre_roll
  - hook
  - benefit_1
  - benefit_2
  - benefit_3
  - ending
  - end_card

# 各类视频素材设置。
sources:
  pre_roll:
    # optional：目录为空时仍可生成；required：为空则禁止生成；disabled：完全不用。
    mode: optional
    directory: "/Volumes/Elements SE/<业务素材目录>/饿了么整理/素材/前贴/260908同步/0.1"
    # 允许扫描的扩展名，不区分大小写。
    extensions: [".mp4", ".mov", ".mkv"]
    # 默认权重。未在 items 中单独声明的文件使用此值。
    default_weight: 1
    items:
      # path 可以写相对 directory 的文件名，也可以写绝对路径。
      - path: "瑞幸咖啡0.1蓝色.mp4"
        enabled: true
        # 权重只在 pre_roll 组内比较；权重 6 不等于固定出现 6 次。
        weight: 6
        # 可选业务标签，便于在任务清单中统计素材归属。
        tags: ["luckin"]
      - path: "蜜雪冰城粉色圣代.mp4"
        enabled: true
        weight: 3
        tags: ["mixue"]

  hook:
    mode: required
    # 相对 source_root 的目录也可以直接写成“引子”。
    directory: "引子"
    extensions: [".mp4"]
    default_weight: 1
    items:
      - path: "1.mp4"
        enabled: true
        # 跑量片段提高权重。
        weight: 5
      - path: "2.mp4"
        enabled: true
        weight: 1

  # 利益点段可增加、删除和在 timeline 中排序。
  # 每段独立抽取一个素材，便于在一条成片中切换不同人物。
  benefit_1:
    mode: required
    directory: "利益点/1"
    extensions: [".mp4"]
    default_weight: 1
    items: []

  benefit_2:
    mode: required
    directory: "利益点/2"
    extensions: [".mp4"]
    default_weight: 1
    items: []

  benefit_3:
    mode: required
    directory: "利益点/3"
    extensions: [".mp4"]
    default_weight: 1
    items: []  # 空数组表示目录内所有有效文件都使用默认权重。

  ending:
    mode: required
    directory: "结尾"
    extensions: [".mp4"]
    default_weight: 1
    items: []

  end_card:
    # disabled 表示当前配置不添加尾帧；改为 required 后必须填写素材。
    mode: disabled
    directory: "/请替换为/淘宝闪购-星广/尾帧目录"
    extensions: [".png", ".jpg", ".jpeg", ".webp", ".mp4"]
    default_weight: 1
    # 静态图片尾帧显示时长，视频尾帧使用自身时长。
    image_duration_seconds: 1.5
    items: []

# 风险提示语图片设置。每个配置固定唯一图片，不参与权重随机，并在所有视频画面之上叠加。
benefit_overlays:
  # required / optional / disabled，含义与视频素材组相同。
  mode: required
  # 必须填写具体图片文件，而不是文件夹。
  file: "/请替换为/淘宝闪购-星广/唯一风险提示语图片.png"

  placement:
    # original：保持原像素尺寸；fit：等比缩放到目标区域；stretch：拉伸到画布。
    scale_mode: original
    # overlay 的 FFmpeg 坐标表达式。0,0 表示左上角；居中可使用 (W-w)/2 和 (H-h)/2。
    x: "0"
    y: "0"
    # 防止超出画布时是否自动等比缩小。
    shrink_if_oversized: true
    # 图片整体透明度，范围 0.0～1.0。
    opacity: 1.0

  timing:
    # full：整条成片；main：不含前贴和尾帧；benefits：全部利益点段；custom：自定义。
    scope: benefits
    # 仅 scope=custom 时生效，单位为秒，以最终成片起点为 0。
    start_seconds: 0
    end_seconds: null

# 视觉去重。旧配置省略本段时默认为关闭。
visual_dedup:
  enabled: false
  foreground:
    # 清晰前景按画布等比缩小并居中，范围 0.70～1.00。
    scale: 0.90
  background:
    mode: gaussian_blur
    sigma: 20.0
    steps: 2
    brightness: 0.0
  border_overlay:
    # disabled / optional / required；每个配置固定一个边框，不随机抽取。
    mode: disabled
    # 受管库可留空并从“视觉去重边框”目录自动发现。
    file: ""
    media_kind: auto
    # exact 要求与输出画布同尺寸，stretch 允许拉伸到画布。
    scale_mode: exact
    playback: loop
    opacity: 1.0
    # straight 为默认；仅在预乘素材出现黑边时尝试 premultiplied。
    alpha_mode: straight

# 产品关联设置。启用后，带产品标签的素材只和相同产品组合。
matching:
  enabled: true
  strategy: product_tag
  # 没有标签的素材是否可以用于所有产品。
  allow_untagged_as_global: true
  # 找不到同标签必需素材时：error 表示报错，fallback_global 表示退回通用池。
  on_missing_match: error

# 权重和随机策略。
randomization:
  # quota_shuffle：按权重分配整批次数再洗牌；independent_random：每条独立加权随机。
  mode: quota_shuffle
  # 核心组合包含“引子 + 全部启用的利益点段 + 结尾”。
  # allow：允许核心组合重复，权重优先。
  # best_effort：保持权重次数并主动重排，尽量减少核心组合重复。
  # strict：唯一组合加权无放回选择，组合唯一优先，素材次数可能偏离权重。
  duplicate_policy: best_effort
  # 留空表示每个批次自动生成随机种子；也可填整数以便复现。
  default_seed: null

# 统一输出规格。输入不一致时由 FFmpeg 标准化。
output:
  directory: "/请替换为/输出目录/淘宝闪购-星广"
  width: 720
  height: 1280
  fps: 30
  # 默认走 Apple VideoToolbox 硬件编解码，失败时自动回退 libx264。
  video_codec: h264_videotoolbox
  pixel_format: yuv420p
  video_preset: medium
  # vbr：按目标平均码率动态分配；crf：按恒定质量动态分配。
  rate_control: vbr
  # 仅 rate_control=vbr 时生效，单位 kbps。
  video_bitrate_kbps: 3000
  # 仅 rate_control=crf 时生效，数值越低画质越高、文件越大。
  crf: 18
  audio_codec: aac
  audio_bitrate: 192k
  audio_sample_rate: 48000
  audio_channels: 2
  # 响度均衡：对每个有声片段处理后再拼接；静音片段不受影响。
  loudness:
    enabled: false
    target_lufs: -14.0       # 目标综合响度，网页支持滑块和数字输入
    loudness_range_lu: 7.0   # 目标响度范围 LU
    true_peak_dbtp: -1.5     # 真峰值上限 dBTP
    preview_duration_seconds: 12.0  # 网页试听截取时长（3～30 秒）
  # fit_pad：等比缩放并补边；fill_crop：等比缩放后居中裁剪；stretch：直接拉伸。
  resize_mode: fit_pad
  background_color: "black"
  # 文件名可用变量：config、date、batch、index、seed。
  filename_template: "{config}_{date}_{batch}_{index:04d}.mp4"
  # increment：重名时自动递增；error：报错；overwrite：覆盖，不建议使用。
  collision_policy: increment
  # 写入 MP4 时启用 faststart，便于快速预览。
  faststart: true
  # 通用视频项目可开启业务动态命名；淘宝闪购项目必须保持 false。
  naming:
    enabled: false
    # 简单设置：产品和利益点由用户维护。
    product: ""
    benefit: ""
    # 可选编号起点，默认从 1 开始；例如填 50 后依次生成 50、51、52……。
    sequence_start: 1
    # 高级设置：达人名和限制日期从抽中的 pool_<n> 素材文件名解析。
    template: "{product}-{benefit}-{talents}-{restriction_date}-{sequence}.mp4"
    source_metadata:
      categories: ["pool_*"]
      strip_smartstitch_suffix: true
      pattern: "^(?P<source_index>\\d+)_(?P<talent>[^-]+)-(?P<source_title>.+)-(?P<restriction_date>\\d{4}-\\d{2}-\\d{2})$"
      restriction_date_formats: ["%Y-%m-%d"]
      on_unmatched: error
    talent:
      merge: ordered_unique
      separator: "+"
    restriction_date:
      merge: earliest
      output_format: "%Y%m%d"
    duplicate_suffix: "-{serial:02d}"

# 批处理设置。界面可在创建任务时覆盖这些默认值。
batch:
  default_count: 10
  max_count: 1000
  concurrency: 2
  retry_count: 1
  # 输出目录至少保留的空间，低于此值不再启动新条目。
  minimum_free_space_gb: 5

# 扫描过滤规则。
scanner:
  recursive: false
  ignore_hidden_files: true
  # macOS 在非原生磁盘上常产生以 ._ 开头的伴生文件，必须忽略。
  ignore_prefixes: ["._", ".~"]
  ignore_names: [".DS_Store"]
```

## 3. 路径解析规则

- `source_root` 必须为绝对路径。
- `hook`、所有 `benefit_<n>`、`ending` 的相对目录默认相对于 `source_root`。
- 其他类别的相对目录也相对于 `source_root`；建议跨目录素材写绝对路径以减少歧义。
- `items[].path` 为相对路径时，相对于该类别的 `directory`。
- 配置加载后统一解析为规范化绝对路径，但保存时可保留用户原始写法。
- 外接硬盘未挂载时应报告“卷未挂载或路径不存在”，不可自动创建同名目录。

### 3.1 标准视频库映射

由 SmartStitch 创建的受管视频库使用以下相对路径：

| 配置项 | 值 |
|---|---|
| `source_root` | 视频库根目录的绝对路径 |
| `sources.pre_roll.directory` | `切片素材/前贴` |
| `sources.hook.directory` | `切片素材/引子` |
| `sources.benefit_<n>.directory` | `切片素材/利益点/<n>` |
| `sources.ending.directory` | `切片素材/结尾` |
| `sources.end_card.directory` | `切片素材/尾帧` |
| `output.directory` | `视频库根目录/成片输出` 的绝对路径 |

`benefit_overlays.file` 不允许填文件夹。受管标准库创库时将其保持为空且 `mode: optional`，扫描器会自动识别库标记所指 `风险提示语图片` 目录中的唯一图片。目录为空时不叠加，多张时预检失败；显式填写 `file` 时优先使用该文件。普通配置仍需填写具体图片路径。

是否属于受管库不通过路径名称猜测，而通过 `source_root/.smartstitch/library.json` 校验。库标记和标准目录见[《标准视频库设计》](./08-标准视频库设计.md)。

### 3.2 通用项目的成片动态命名

- 仅 `workflow_type: generic` 可以启用 `output.naming.enabled`；关闭时继续使用 `output.filename_template`。
- 简单设置展示开关、`product`、`benefit`、`sequence_start` 和结果预览。解析正则、参与视频库、日期格式、合并方式与重名后缀放在高级设置。
- 默认素材名格式为 `编号_达人名-中间文案-YYYY-MM-DD.mp4`。例如 `00016_小慧不大乖-红果拿下了我全家-2026-11-14.mp4` 会提取达人名 `小慧不大乖` 和限制日期 `2026-11-14`。
- `strip_smartstitch_suffix: true` 时，先移除切片工具产生的 `__...` 后缀，再按正则解析原素材名。
- 一条成片从多个视频库取材时，达人名按 `timeline` 顺序去重后以 `+` 拼接；限制日期取所有参与素材中的最早日期。
- 默认输出为 `产品-利益点-达人名-限制日期-序号.mp4`。`sequence_start` 默认是 `1`，用户可在 04 命名设置中改为 `50` 等正整数；随后每条成片依次递增。最终文件名会替换跨平台非法字符并限制为 240 个 UTF-8 字节。
- 扫描预检会检查所有参与命名且可抽取的素材。任何文件无法提取达人名或限制日期时，必须先修正文件名或高级规则，任务才可生成。

完整交互、边界与迁移设计见[《成片动态命名与素材元数据拼接设计》](./16-成片动态命名与素材元数据拼接设计.md)。

## 4. 权重与启用规则

- `enabled: false` 的条目不参与抽取。
- `weight: 0` 的条目不参与抽取，但与停用状态分别展示。
- 未在 `items` 中列出的扫描文件使用 `default_weight`。
- 同一路径若在 `items` 中重复出现，配置校验失败。
- 必需类别中所有条目均停用或权重为 0 时，配置校验失败。

## 5. 多段利益点规则

- 利益点键名必须匹配 `benefit_<n>`，其中 `n` 为从 1 开始的正整数，暂时最多 20 段。
- 每段必须同时存在于 `sources` 和 `timeline`；顺序以 `timeline` 为准。
- 段编号是稳定标识，删除中间段后允许留下不连续编号，不自动重命名。
- 删除一段需同时从 `sources` 和 `timeline` 移除它；这个操作不删除 `directory` 指向的本地文件。
- 受管视频库中新建一段时，必须由后端同时创建 `切片素材/利益点/<n>` 并保存配置；前端不得只在未保存草稿中追加该段。
- 至少保留一个非 `disabled` 利益点段。建议利益点默认使用 `required`；`optional` 组没有可用素材时会跳过。
- schema 1 的 `benefit_video` 加载时迁移为 `benefit_1`，老的叠图范围 `benefit_video` 迁移为 `benefits`。
- 完整迁移、渲染和清单规则见[《多段利益点配置设计》](./07-多段利益点配置设计.md)。

## 6. 配置拆分建议

为便于人工维护，正式实现可采用：

```text
config/
├── template.commented.yaml        # 永久保留的全注释模板
├── taobao-xingguang.yaml          # 淘宝闪购-星广
├── taobao-standard.yaml           # 淘宝闪购-常规
└── backups/                       # 前端保存前的历史版本
```

不同配置可以引用同一主素材目录，但分别设置风险提示语图片、前贴、尾帧、权重和输出目录。
