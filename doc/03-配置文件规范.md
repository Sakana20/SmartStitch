# SmartStitch 配置文件规范

## 1. 格式原则

- 使用 UTF-8 编码的 YAML。
- 配置文件允许中文路径、中文名称和中文注释。
- 路径建议使用绝对路径；环境迁移时可在前端重新选择。
- 示例中的字段名称是第一版建议，开发时应通过 Pydantic 模型严格校验。
- 前端保存配置时应尽量保留注释；若所用 YAML 库不能保留注释，则保留一份人工维护的模板文件，并将界面生成配置与模板分开。

## 2. 完整注释示例

```yaml
# 配置格式版本。未来字段升级时用于自动迁移，请勿随意修改。
schema_version: 1

# 配置的唯一标识。只用小写英文、数字、短横线，创建后不建议修改。
id: taobao-xingguang

# 前端展示名称。
name: "淘宝闪购-星广"

# 是否允许在创建任务时选择此配置。
enabled: true

# 对此配置用途的说明，不参与视频生成。
description: "星广一口价 25 元素材组合"

# 主素材目录。其下应包含“引子”“利益点”“结尾”三个子目录。
source_root: "/Volumes/Elements SE/<业务素材目录>/饿了么整理/素材/星广一口价/25元/分割后"

# 成片片段顺序。第一版支持以下五种名称。
# 禁用某个可选类别时，该类别会从时间线中跳过。
timeline:
  - pre_roll
  - hook
  - benefit_video
  - ending
  - end_card

# 各类视频素材设置。
sources:
  pre_roll:
    # optional：目录为空时仍可生成；required：为空则禁止生成；disabled：完全不用。
    mode: optional
    directory: "/Volumes/Elements SE/<业务素材目录>/饿了么整理/素材/前贴/260908同步/0.1"
    # 允许扫描的扩展名，不区分大小写。
    extensions: [".mp4", ".mov", ".mkv"]
    # 默认权重。未在 items 中单独声明的文件使用此值。
    default_weight: 1
    items:
      # path 可以写相对 directory 的文件名，也可以写绝对路径。
      - path: "瑞幸咖啡0.1蓝色.mp4"
        enabled: true
        # 权重只在 pre_roll 组内比较；权重 6 不等于固定出现 6 次。
        weight: 6
        # 可选业务标签，便于在任务清单中统计素材归属。
        tags: ["luckin"]
      - path: "蜜雪冰城粉色圣代.mp4"
        enabled: true
        weight: 3
        tags: ["mixue"]

  hook:
    mode: required
    # 相对 source_root 的目录也可以直接写成“引子”。
    directory: "引子"
    extensions: [".mp4"]
    default_weight: 1
    items:
      - path: "1.mp4"
        enabled: true
        # 跑量片段提高权重。
        weight: 5
      - path: "2.mp4"
        enabled: true
        weight: 1

  benefit_video:
    mode: required
    directory: "利益点"
    extensions: [".mp4"]
    default_weight: 1
    items: []  # 空数组表示目录内所有有效文件都使用默认权重。

  ending:
    mode: required
    directory: "结尾"
    extensions: [".mp4"]
    default_weight: 1
    items: []

  end_card:
    # disabled 表示当前配置不添加尾帧；改为 required 后必须填写素材。
    mode: disabled
    directory: "/请替换为/淘宝闪购-星广/尾帧目录"
    extensions: [".png", ".jpg", ".jpeg", ".webp", ".mp4"]
    default_weight: 1
    # 静态图片尾帧显示时长，视频尾帧使用自身时长。
    image_duration_seconds: 1.5
    items: []

# 利益点图片设置。每个配置固定唯一图片，不参与权重随机，并在所有视频画面之上叠加。
benefit_overlays:
  # required / optional / disabled，含义与视频素材组相同。
  mode: required
  # 必须填写具体图片文件，而不是文件夹。
  file: "/请替换为/淘宝闪购-星广/唯一利益点图片.png"

  placement:
    # original：保持原像素尺寸；fit：等比缩放到目标区域；stretch：拉伸到画布。
    scale_mode: original
    # overlay 的 FFmpeg 坐标表达式。0,0 表示左上角；居中可使用 (W-w)/2 和 (H-h)/2。
    x: "0"
    y: "0"
    # 防止超出画布时是否自动等比缩小。
    shrink_if_oversized: true
    # 图片整体透明度，范围 0.0～1.0。
    opacity: 1.0

  timing:
    # full：整条成片；main：不含前贴和尾帧；benefit_video：仅利益点视频；custom：自定义。
    scope: benefit_video
    # 仅 scope=custom 时生效，单位为秒，以最终成片起点为 0。
    start_seconds: 0
    end_seconds: null

# 产品关联设置。启用后，带产品标签的素材只和相同产品组合。
matching:
  enabled: true
  strategy: product_tag
  # 没有标签的素材是否可以用于所有产品。
  allow_untagged_as_global: true
  # 找不到同标签必需素材时：error 表示报错，fallback_global 表示退回通用池。
  on_missing_match: error

# 权重和随机策略。
randomization:
  # quota_shuffle：按权重分配整批次数再洗牌；independent_random：每条独立加权随机。
  mode: quota_shuffle
  # allow / best_effort / strict。
  duplicate_policy: best_effort
  # 留空表示每个批次自动生成随机种子；也可填整数以便复现。
  default_seed: null

# 统一输出规格。输入不一致时由 FFmpeg 标准化。
output:
  directory: "/请替换为/输出目录/淘宝闪购-星广"
  width: 720
  height: 1280
  fps: 30
  video_codec: libx264
  pixel_format: yuv420p
  video_preset: medium
  # vbr：按目标平均码率动态分配；crf：按恒定质量动态分配。
  rate_control: vbr
  # 仅 rate_control=vbr 时生效，单位 kbps。
  video_bitrate_kbps: 3000
  # 仅 rate_control=crf 时生效，数值越低画质越高、文件越大。
  crf: 18
  audio_codec: aac
  audio_bitrate: 192k
  audio_sample_rate: 48000
  audio_channels: 2
  # 响度均衡：对每个有声片段处理后再拼接；静音片段不受影响。
  loudness:
    enabled: false
    target_lufs: -14.0       # 目标综合响度，网页支持滑块和数字输入
    loudness_range_lu: 7.0   # 目标响度范围 LU
    true_peak_dbtp: -1.5     # 真峰值上限 dBTP
    preview_duration_seconds: 12.0  # 网页试听截取时长（3～30 秒）
  # fit_pad：等比缩放并补边；fill_crop：等比缩放后居中裁剪；stretch：直接拉伸。
  resize_mode: fit_pad
  background_color: "black"
  # 文件名可用变量：config、date、batch、index、seed。
  filename_template: "{config}_{date}_{batch}_{index:04d}.mp4"
  # increment：重名时自动递增；error：报错；overwrite：覆盖，不建议使用。
  collision_policy: increment
  # 写入 MP4 时启用 faststart，便于快速预览。
  faststart: true

# 批处理设置。界面可在创建任务时覆盖这些默认值。
batch:
  default_count: 10
  max_count: 1000
  concurrency: 2
  retry_count: 1
  # 输出目录至少保留的空间，低于此值不再启动新条目。
  minimum_free_space_gb: 5

# 扫描过滤规则。
scanner:
  recursive: false
  ignore_hidden_files: true
  # macOS 在非原生磁盘上常产生以 ._ 开头的伴生文件，必须忽略。
  ignore_prefixes: ["._", ".~"]
  ignore_names: [".DS_Store"]
```

## 3. 路径解析规则

- `source_root` 必须为绝对路径。
- `hook`、`benefit_video`、`ending` 的相对目录默认相对于 `source_root`。
- 其他类别的相对目录也相对于 `source_root`；建议跨目录素材写绝对路径以减少歧义。
- `items[].path` 为相对路径时，相对于该类别的 `directory`。
- 配置加载后统一解析为规范化绝对路径，但保存时可保留用户原始写法。
- 外接硬盘未挂载时应报告“卷未挂载或路径不存在”，不可自动创建同名目录。

## 4. 权重与启用规则

- `enabled: false` 的条目不参与抽取。
- `weight: 0` 的条目不参与抽取，但与停用状态分别展示。
- 未在 `items` 中列出的扫描文件使用 `default_weight`。
- 同一路径若在 `items` 中重复出现，配置校验失败。
- 必需类别中所有条目均停用或权重为 0 时，配置校验失败。

## 5. 配置拆分建议

为便于人工维护，正式实现可采用：

```text
config/
├── template.commented.yaml        # 永久保留的全注释模板
├── taobao-xingguang.yaml          # 淘宝闪购-星广
├── taobao-standard.yaml           # 淘宝闪购-常规
└── backups/                       # 前端保存前的历史版本
```

不同配置可以引用同一主素材目录，但分别设置利益点图片、前贴、尾帧、权重和输出目录。
