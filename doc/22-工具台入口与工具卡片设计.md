# 工具台入口与工具卡片设计

状态：入口与卡片框架、SmartStitch 集群控制的主控和工作机操作已实现。

## 1. 目标与范围

在首页导航栏右端（截图红框位置）增加“工具台”页签。它与左侧“创建任务 / 时间线切片 / 素材权重 / 任务记录”属于同一级页面，沿用现有页签的文字、颜色、选中下划线和切换方式。

进入工具台后，展示可逐步扩充的小工具入口。工具以大图卡片呈现，宽屏时每行 5 张。典型用途包括“选择两个文件夹进行拼接”和“批量调用现有能力做去重”。当前先确定入口、布局和状态规范；每个工具的处理规则与接口随具体需求单独设计。

## 2. 页面结构

```text
创建任务  时间线切片  素材权重  任务记录                         工具台
─────────────────────────────────────────────────────────────────────

工具台
常用工具集中在这里，选择卡片进入对应功能。

┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐
│ 大图    │ │ 大图    │ │ 大图    │ │ 大图    │ │ 大图    │
│ 名称    │ │ 名称    │ │ 名称    │ │ 名称    │ │ 名称    │
│ 简介    │ │ 简介    │ │ 简介    │ │ 简介    │ │ 简介    │
└─────────┘ └─────────┘ └─────────┘ └─────────┘ └─────────┘
```

- 导航：使用现有 `section-tabs` / `section-tab`。工具台页签排在 DOM 最后，视觉上靠右；窄屏时允许导航横向滚动，保证入口可触达，不挤压其他页签。
- 页面：新增与其他页面同级的 `toolboxView`。页首使用现有 `panel`、`panel-heading`、标题字体与间距。主内容为工具卡片网格。
- 布局：桌面宽度每行 5 张；空间不足时依次变为 3 列、2 列、1 列。卡片保持统一宽度、图片比例和文字区高度，新增工具自然换行，不人为限制总数为 5。
- 大图：每卡上部为固定比例的封面图区域，建议 4:3；下部显示名称和一句简短用途。图片使用项目本地静态资源，提供同色系默认封面，避免缺图时布局跳动。整张卡片可点击，并有键盘焦点、悬停与禁用状态。
- 视觉：只使用当前的绿色、薄荷绿、中性色、圆角、边框和阴影。卡片应与现有 `panel` 风格一致；不另建图标体系或引入前端框架。

### 点击卡片后的轻量操作面板

小工具在工具台内容区打开，替换卡片网格；顶部保留“← 返回工具台”、工具名称和一句用途说明。面板优先采用“选择输入 → 设置少量参数 → 执行 → 查看结果”的单页流程，不为每个工具增加顶部导航页签或多层详情页。任一时刻只显示一个工具面板；返回后恢复卡片列表。

文件夹、文件等输入沿用项目现有路径选择交互；执行按钮、进度、错误和结果沿用当前任务及提示样式。耗时任务应交给现有后端任务机制处理，离开面板后仍能找到任务状态；具体是否纳入“任务记录”，由该工具的任务协议确定。

## 3. 工具状态与首版内容

建议工具台只展示已经明确名称和用途的工具。首版若尚无工具，展示“工具即将加入”空状态，不用五个没有功能的假入口占位。第一个工具确定后再出现首张大图卡片；同一行最多 5 张。

工具卡片由统一清单生成，不在 HTML 中逐张写死，也不按“恰好 5 个”限制数量。清单负责展示和打开对应工具；每个工具自己的表单、校验、执行与结果逻辑独立维护。后续增加第 6 张卡片时，卡片自动换到下一行，不需要修改网格或主导航。

后续每个工具至少定义：

| 字段 | 用途 |
| --- | --- |
| 稳定 ID | 绑定入口与功能，改名后保持不变 |
| 名称、简介 | 卡片展示与无障碍名称 |
| 封面图 | 本地图片路径；缺图时使用默认封面 |
| 状态 | 可用、暂不可用；不可用时说明原因 |
| 操作面板 | 工具台内的输入、执行与结果内容 |
| 排序 | 决定卡片在网格中的位置，新增工具不依赖代码插入顺序 |

前端登记方式（示意）：

```js
const toolboxTools = [
  {
    id: "folder-concat",
    title: "文件夹拼接",
    description: "选择两个文件夹，批量拼接视频",
    cover: "/assets/tools/folder-concat.webp",
    order: 10,
    mount: mountFolderConcatTool,
  },
];
```

新增工具按固定步骤完成：登记稳定 ID 和卡片文案、准备封面或使用默认封面、实现该工具的操作面板与执行接口、补充该工具自身的校验和验收。卡片网格只读取清单，不包含针对具体工具名称的分支。工具未完成时可登记为 `mount: null`，卡片显示“即将加入”且不可点击；尚无明确需求时不登记空白卡片。

工具台是全局导航，不默认绑定当前“使用配置”。如果某个工具需要配置或素材，进入该工具后再明确选择和校验，避免从创建任务页隐式继承旧配置。

## 4. 交互约定

1. 点击“工具台”切换到工具台内容区，页签高亮逻辑与当前四个页面相同。
2. 从“素材权重”离开时，继续执行现有未保存修改确认与编辑锁释放；进入工具台不绕过该流程。
3. 工具卡片可用时点击打开对应操作面板；暂不可用时显示原因，不触发空白页面。
4. 返回工具台后保留原有导航体系；工具内容不挤进创建任务、配置管理或任务记录。
5. 窄屏时卡片顺序与桌面一致，按工具定义顺序从左到右、从上到下排列。

## 5. 实现落点（待方案确认后）

- `frontend/index.html`：在现有导航尾部增加 `data-view="toolbox"` 页签和同级 `toolboxView`。
- `frontend/styles.css`：扩展导航右对齐与横向滚动规则；增加工具卡片网格和响应式样式，复用现有设计变量。
- `frontend/app.js`：复用 `switchView()`；以一份工具定义列表渲染卡片，按稳定 ID 分发点击，并控制“卡片列表 / 当前工具面板”。各工具的输入、执行与结果逻辑分开维护，避免堆成一个大型条件分支。工具数量不写入导航或布局逻辑。
- 静态资源版本：前端实际修改时同步更新 CSS、JS 的缓存版本。

## 6. 验收要点

- 页签处于截图红框的右侧区域，视觉规格与左侧四个页签一致；选中后只显示工具台页面。
- 桌面宽度一行恰好容纳 5 张大图卡片，第 6 张自动换行；窄屏无水平溢出。
- 登记一个新工具后，卡片自动出现并能打开自己的面板；移除或停用工具不影响其他卡片及其顺序。
- 空状态、缺图、禁用、悬停和键盘焦点均可读且布局稳定。
- 从素材权重页切走时，现有未保存修改与锁逻辑正常；其他四个页面不受影响。

首批可按以下方向逐个设计；这些是需求线索，尚不代表处理规则已确定：

| 工具方向 | 操作面板初步输入 | 需要单独确定的规则 |

## 8. SmartStitch 集群控制

- 位于工具台第一张卡片，仅管理员登录后可见。App 启动时本机工作机默认上线；管理员可手动下线或重新上线、开启令牌保护、用 Bonjour 搜索或手动添加工作机、查看在线节点、提交集群渲染批次、查看和取消集群任务。
- 工具台集群控制接口使用管理员账号会话鉴权；不再提供独立的集群控制密码或临时解锁令牌。
- 工作机的局域网接口只提供握手、接收执行、查询状态和取消执行，默认不校验工作机令牌。管理员可手动开启令牌保护，随机令牌按本机保存。工作机局域网接口适用于受信任内网；跨不可信网络需增加 TLS 或安全隧道。集群具体架构、恢复边界和双机验收见 [多机集群渲染可行性研究](24-多机集群渲染可行性研究.md)。

## 9. ProRes 4444 处理

工具台“ProRes 4444 处理”卡片排在用户管理占位之后。用户选择一个源视频文件夹，工具扫描该文件夹第一层的 MP4、MOV、M4V、MKV（扩展名大小写不敏感）。读取视频后，像切片分类一样逐条选择保存位置：默认输出回源视频文件夹，也可选择全局素材库中当前存在的任一视觉特效库。每次读取视频都重新获取特效库列表，后续新增的 `effect_N` 会自动成为选项；后端校验所选编号对应未删除的库，且只允许写入配置根目录下该库的目录。源文件保留，不递归扫描子目录；已生成的 `_Alpha.mov` 视频不重复作为输入。相同主文件名的不同格式会造成输出冲突，提交前拒绝并提示重命名。

转换滤镜与 `/Users/sakana/Desktop/test/1.command` 的实际 FFmpeg 命令一致：`format=rgba` 后用 RGB 最大值作为 Alpha，将超过阈值 3 的 RGB 按最大值归一化，最后转为 `yuva444p10le`，使用 `prores_ks` profile 4、`-qscale:v 64` 编码并移除音频。脚本顶部注释写 `qscale 15`，实际命令为 64；这里按实际命令执行。输出文件通常命名为 `<原文件名不含扩展名>_Alpha.mov`；快捷特效库内已有同名文件时自动加数字后缀，避免覆盖已入库素材。输出先写临时 MOV，成功后替换目标，失败时删除临时文件并继续处理其余视频。

面板显示总进度、当前文件和逐条成功或失败结果；切回工具台或刷新页面后可读取当前进程内的最近一次任务。桌面应用退出时将此任务计入运行中任务提示，并终止正在运行的 FFmpeg。任务状态仅保存在进程内，应用重启后不恢复历史记录。

## 10. 超分占位

工具台新增“超分”卡片，排在 ProRes 4444 处理之后。当前仅展示本地封面和“即将加入”状态，不提供操作面板或执行接口。算法、输入输出和任务流程已在[视频超分接入设计](25-视频超分接入设计.md)中明确，待实现与验证后开放。

## 11. 用户管理占位

工具台“用户管理”卡片排在集群控制之后，仅管理员可见。面板支持添加、暂停、恢复、删除用户，以及角色和密码管理。

账号登录和权限规则见[账号登录与管理员用户管理设计](27-账号登录与管理员用户管理设计.md)。
