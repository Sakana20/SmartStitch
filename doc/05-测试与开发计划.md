# SmartStitch 测试与开发计划

## 1. 开发阶段

### 阶段一：配置与素材预检

- 建立 Python 项目、配置模型和注释模板。
- 实现路径解析、素材扫描、过滤和 ffprobe 缓存。
- 实现配置校验和预检报告。
- 实现 schema 1 `benefit_video` 到 schema 2 `benefit_1` 的无损加载迁移，以及动态利益点段校验。
- 单元测试覆盖中文路径、空格路径、`._` 文件、缺失目录和异常媒体。

交付判断：给定当前素材目录，可稳定列出有效素材及媒体规格，不写任何成片。

### 阶段二：组合计划与权重

- 实现配额洗牌、独立随机、随机种子和组合去重。
- 使计划器和去重签名动态包含所有启用的 `benefit_<n>` 素材组。
- 实现产品标签关联。
- 输出计划预览、理论/实际分布和 JSON 清单。

交付判断：相同输入和种子计划可复现，权重统计符合规则。

### 阶段三：FFmpeg 渲染

- 实现视频/音频标准化。
- 实现时间线 concat、静态/视频尾帧、透明图片最高层 overlay。
- 实现临时文件、结果探测、错误分类和重试。

交付判断：用小型测试素材完成端到端渲染，成片要素、时长、音画和叠图正确。

### 阶段四：后端任务系统

- 实现 API、SQLite、任务队列、并发限制、取消与恢复标记。
- 实现 JSON/CSV 清单和配置快照。
- 实现 SSE 进度推送。

交付判断：批量任务单条失败不拖垮整批，服务重启后状态可解释。

### 阶段五：前端

- 配置列表与编辑。
- 将利益点编辑改为可添加、删除和排序的段列表。
- 素材表格、权重和概率显示。
- 任务创建、计划预览、进度和结果页面。
- 完成基础易用性和错误提示。
- 完成 PR 式时间标尺栏、片段轨道和贯穿式播放头，并与视频播放器保持帧级同步。
- 完成基于时间线视口坐标的跟手拖动、缩放后逐帧定位和按住 Shift 才启用的吸附反馈。

交付判断：日常任务无需操作命令行即可完成。

### 阶段六：真实素材验收与打包

- 使用外接硬盘上的真实素材做受控小批量测试。
- 验证长路径、中文路径、磁盘拔出、空间不足和取消任务。
- 提供本机启动脚本、安装说明和故障排查文档。

### 阶段七：标准视频库与批量切片入库

- 实现本机目录选择、建库预检和标准目录的原子创建。
- 实现 `.smartstitch/library.json` 的读写、版本校验和库健康检查。
- 新建视频库时生成指向标准目录的 schema 2 配置。
- 将“添加利益点”改为后端幂等操作，同时建目录、修改时间线、修改素材组和递增库编号。
- 实现审核片段的批量切割、分类入库、`.part` 提交和切片清单。
- 保留外部素材配置的扫描与生成兼容性，不自动搬迁旧目录。

交付判断：用户选择一次保存位置后即可获得完整视频库，后续利益点段和批量切片均可自动落入正确目录并可追溯。

## 2. 测试矩阵

### 2.1 配置测试

| 场景 | 期望结果 |
|---|---|
| 合法完整配置 | 校验通过 |
| 负权重 | 指明字段并拒绝 |
| 必需组权重总和为 0 | 拒绝启动 |
| 相对路径 | 按定义的基准目录正确解析 |
| 外接卷未挂载 | 明确提示，不创建替代目录 |
| 配置保存中断 | 原配置仍可读取 |
| schema 1 单利益点配置 | 加载为 `benefit_1`，不立即覆盖原文件 |
| 删除中间利益点段 | 允许稳定编号不连续，时间线顺序正确 |
| 删除最后一个启用利益点段 | 拒绝保存并说明至少需要一段 |
| `timeline` 引用不存在的 `benefit_<n>` | 指明标识并拒绝 |
| 利益点段超过 20 个 | 拒绝并提示上限 |

### 2.2 扫描测试

| 场景 | 期望结果 |
|---|---|
| `._视频.mp4` | 忽略 |
| 大写 `.MP4` | 正常识别 |
| 文件无视频流 | 标记无效 |
| 视频无音轨 | 允许并在渲染时补静音 |
| VFR 视频 | 标记并标准化为目标帧率 |
| 中文和空格路径 | 正常探测 |
| 扫描期间文件被删除 | 报告具体文件，不崩溃 |

### 2.3 权重测试

| 场景 | 期望结果 |
|---|---|
| 权重 6/3/1，数量 10，配额模式 | 次数 6/3/1 |
| 权重 6/3/1，数量 7，配额模式 | 总和为 7，按最大余数稳定分配 |
| 固定种子重复执行 | 计划一致 |
| 不同种子 | 次数配额相同但顺序通常不同 |
| strict 去重且数量超组合空间 | 创建任务失败并提示最大数量 |
| 产品标签不匹配 | 按配置报错或退回通用池 |
| 三个利益点段各有多个候选 | 每段独立按权重分配，每条计划按时间线含三段 |
| strict 去重与三个利益点段 | 最大组合数包含三个素材池的乘积 |

### 2.4 渲染测试

| 场景 | 期望结果 |
|---|---|
| 全部输入规格一致 | 正常成片 |
| 分辨率、帧率不同 | 统一为输出规格 |
| 某片段无音频 | 成片时间线和音频连续 |
| 透明 PNG | 透明正确且位于最高层 |
| 全部利益点段叠图 | 从实际第一段开始到最后一段结束，起止由累计时长计算 |
| 时间线删减一个利益点段 | FFmpeg 输入、concat 顺序和预计时长同步减少该段 |
| 静态尾帧 1.5 秒 | 输出末尾持续约 1.5 秒 |
| FFmpeg 中途失败 | 无正式半成品，记录失败 |
| 输出重名 | 按冲突策略处理 |

### 2.5 任务测试

| 场景 | 期望结果 |
|---|---|
| 10 条中 1 条失败 | 其余继续，批次为 partial_failed |
| 用户取消 | 待执行项取消，临时文件安全处理 |
| 服务意外退出 | 重启后运行中任务标为 interrupted |
| SSE 断线重连 | 前端能恢复真实状态 |
| 磁盘空间跌破阈值 | 不启动新条目并给出告警 |

### 2.6 时间线审核测试

| 场景 | 期望结果 |
|---|---|
| 视频正常播放 | 时间标尺手柄和贯穿轨道的播放头竖线跟随实际呈现帧 |
| 视频时间停在某帧后半段 | 回退同步仍显示当前画面帧，不因四舍五入提前到下一帧 |
| 手动定位相邻帧或小于四分之一帧的时间差 | 播放器仍精确 seek 到目标帧，不保留旧画面 |
| 真实素材在断点帧起点仍呈现前一帧 | 预览 seek 使用目标帧中点，画面显示后一段首帧；断点权威帧号和时间码不偏移 |
| 拖动播放器进度条 | 时间线播放头、帧号和时间码同步到同一帧 |
| 时间标尺与轨道水平滚动 | 刻度、断点、片段边界和播放头保持横向对齐 |
| 切换多档缩放 | 主次刻度密度自适应，时间码标签不重叠 |
| 鼠标悬停时间线并按空格 | 视频在播放和暂停之间切换，页面不发生滚动；长按不重复切换 |
| 鼠标离开时间线后按空格 | 不拦截页面默认行为，也不切换视频播放状态 |
| 按住 Option 在时间线上滚轮滚动 | 以鼠标所在时间点为锚点平滑放大或缩小时间线 |
| 未按 Option 使用滚轮 | 不触发缩放，保留时间线正常滚动行为 |
| 单击或拖动时间标尺 | 播放头与鼠标横坐标同步，不出现固定比例减速或累计偏移 |
| 单击、双击或拖动下方轨道空白处 | 播放头和断点均不变化 |
| 拖动下方轨道中的断点 | 只调整该断点；播放头竖线、视频画面和当前播放帧保持不变 |
| 快速连续拖动 | 界面按最新指针位置刷新，无明显事件积压和松手后追赶 |
| 默认拖动经过断点 | 不发生吸附，播放头继续跟随鼠标 |
| 按住 Shift 进入断点 8 px 范围 | 吸附到目标帧，并高亮目标断点和时间码 |
| 按住 Shift 将断点拖入播放头 8 px 范围 | 断点吸附到播放头所在帧，播放头竖线、视频画面和当前播放帧不变化 |
| Shift 吸附后在 8～12 px 范围抖动 | 保持吸附，不在自由位置与目标间反复切换 |
| 拖动中松开 Shift | 立即解除吸附并回到鼠标对应位置，不发生跳回 |
| 多个吸附目标距离相同 | 按播放头、人工点、机器点、较小帧序号的顺序稳定选择 |
| 拖动已有断点到另一断点 | 不创建重复断点，按交互规则选中或保留已有点 |
| 拖动过程中松开到窗口外 | 正常结束拖动并恢复一致状态，不遗留捕获或暂停状态 |
| 视频播放中移动时间标尺播放头 | 移动时暂停，松开后仍保持暂停，不自动恢复 |
| 视频播放中拖动断点 | 拖动期间暂停；断点提交后恢复原播放状态，播放头位置不被断点改写 |
| 保存后重新加载 | 断点整数帧、顺序和片段范围保持不变 |
| 放大到单帧至少 4 px | 25/30/50/60 fps CFR 视频中可稳定选择相邻帧 |
| VFR 视频 | 明确标记近似帧率限制；不得静默声称达到 CFR 同等精度 |

### 2.7 标准视频库测试

| 场景 | 期望结果 |
|---|---|
| 未选保存位置 | 新建按钮不可用，不写盘 |
| 取消目录选择器 | 保持原表单，不创建配置或文件夹 |
| 中文与空格路径 | 创建完整目录树，配置可正确扫描 |
| 同名最终目录已存在 | 返回冲突，不合并且不改写已有内容 |
| 保存位置只读 | 预检拦截并显示具体路径 |
| 外接卷未挂载 | 报错且不在其他位置创建替代目录 |
| 标准建库成功 | 全部必需目录、库标记和 schema 2 配置一致 |
| 建库中任一步失败 | 不留下可被误认为成功库的半成品 |
| 同一建库请求重试 | 返回同一结果，不创建重复库 |
| 受管库添加利益点 | 目录、`sources`、`timeline` 和递增编号同步成功 |
| 连续或并发添加利益点 | 每个请求获得唯一且单调递增的编号 |
| 利益点目标目录已有视频 | 保留全部内容并关联目录，不覆盖 |
| 删除利益点后再添加 | 原目录保留，新段使用从未使用的更大编号 |
| 库内目标是越界符号链接 | 拒绝写入并指明安全原因 |
| 外部素材旧配置 | 照常扫描和生成，不自动创建整套标准目录 |
| 批量切片成功 | 视频进入目标素材池，清单记录源指纹、帧区间和输出路径 |
| 批量切片中单条失败 | 其他条目继续，无正式半成品，清单保留错误 |
| 断点列表改为片段选择 | `N` 个断点生成 `N + 1` 个可点击区间；默认列表为空，连续点击后累计添加且不重复 |
| 批量选择类型 | 同一列表内多条可分别选择前贴、引子、动态利益点、结尾、尾帧和未归类 |
| 调整断点后分类安全性 | 只保留帧区间完全未变的分类，受影响片段重置为待分类 |
| 单列表批量操作 | 不显示第二套批量区域；支持从片段列表移除误选条目 |
| 未标记任何片段 | 片段列表为空并阻止切片；未选择的其他片段不影响列表子集执行 |
| 切片审核版本过期 | 返回冲突且不启动 FFmpeg，不使用界面草稿切割 |

## 3. 真实素材验收建议

开发完成后按以下顺序验证，避免一开始就生成大量文件：

1. 只扫描当前目录并保存预检报告。
2. 固定种子生成 3 条计划，不渲染。
3. 渲染 1 条到临时输出目录，人工查看顺序和叠图。
4. 渲染 3 条，核对清单与实际内容。
5. 设置明显权重差异，生成 10 条并核对次数。
6. 人工制造一个无效素材，验证单条失败行为。
7. 最后再进行实际每日批量规模的压力测试。

## 4. 性能与容量

- 记录单条视频的渲染耗时、CPU 使用和输出大小，据此决定默认并发数。
- 配额计划生成应在千条规模下近乎即时。
- ffprobe 缓存应避免每次打开页面都重新探测全部素材。
- 日志应轮转或按批次存放，防止长期使用占满磁盘。

## 5. 开发前待确认事项

以下事项不阻碍文档设计，但写代码前最好确认：

1. 风险提示语图片默认覆盖“整条成片”还是“全部利益点段”。当前 schema 2 示例采用“全部利益点段”。
2. 前贴是每条必需、可选随机，还是只对部分配置启用。当前示例采用“可选”。
3. 尾帧是静态图片、视频，还是两者都有。设计已兼容两者。
4. 产品前贴与风险提示语图片是否必须同产品匹配。当前设计默认启用产品标签匹配。
5. 已确认一条成片可包含多个利益点段，并由 schema 2 配置增删和排序；开发时按[《多段利益点配置设计》](./07-多段利益点配置设计.md)验收。
6. 每日常见生成数量和可接受耗时，用于确定默认并发和质量参数。
7. “淘宝闪购-常规”的实际素材、风险提示语图片和尾帧目录。
8. 成片是否需要限定总时长，或允许由所选片段自然相加。

## 6. 完成定义

只有同时满足以下条件，第一版才算完成：

- 文档中的核心验收标准全部通过。
- 自动化测试通过，真实素材小批量验收通过。
- 无需修改 Python 代码即可通过配置新增“淘宝闪购-常规”等场景。
- 任一输出视频都能追溯到输入素材、权重、随机种子和配置快照。
- 用户可仅通过网页完成配置、预览、生成、查看进度和定位结果。
