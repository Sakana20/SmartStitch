# 自动分割视频与积木命名

## 使用流程

工具台 → 自动分割视频 → 选择一个 MP4、MOV、M4V、MKV 或 WebM 视频 → 设置输出位置、起始序号或积木命名 → 自动检测并预览分段 → 开始分割。

默认自动检测，无需填写黑屏秒数，也不假定所有分隔黑屏都一样长。用 `blackdetect` 测量每处黑屏起止时间，支持 0.5、1、3、7、10 秒等混合长度；预览显示分隔黑屏实际时长范围和每处的起止、持续时间。像素亮度阈值为 0.10，黑色画面比例为 0.95，允许黑底上存在少量固定标识、字幕或合规文字。自动模式扫描至少 0.05 秒的黑屏，短于 0.3 秒的闪黑保留在片段内，防止瞬间闪黑引入额外切点；未使用的短黑屏也计入检测快照。片头和片尾的分隔黑屏去掉，不生成空片段。没有可用于分段的黑屏时预览提示并导出整条视频，全黑视频拒绝提交。

## 命名

关闭积木命名时，输出为 `01.mp4`、`02.mp4` 等，起始序号设为 21 则为 `21.mp4`、`22.mp4` 等。

开启后复用 `renderBuilderEditor`、`bindBuilderControls` 和后端 `derive_plan_naming` / `render_plan_filename`。源视频是 `pool_1`，文件名字段按 `|!|` 分隔。支持素材字段、可编辑文字、日期和序号块及拖动排序；序号取积木编辑器中的起点。每个片段使用同一个源视频文件名，序号随片段顺序增加。重名使用现有递增后缀，非法字段、非法文件名和序号溢出在提交前拒绝。日期按本次预览或提交时冻结。

“用实际素材验证文件名”只验证文件名：根据源文件名、积木规则和起始序号生成第一段的命名示例，不读取视频、不调用 ffprobe/FFmpeg、不检测黑屏。此操作只更新命名区域，不清空或生成分段预览，也不改变“开始分割”按钮状态。只有“检测并预览分段”执行黑屏检测。

## 检测与导出

- `POST /api/v1/tools/auto-video-split/naming-preview`：仅接受 `source_file`、`sequence_start` 和 `naming`，只验证命名，返回 `output_name`、`source_name`、`sequence` 和 `block_values`；不探测媒体内容，也不要求源文件已存在。
- `POST /api/v1/tools/auto-video-split/preview`：检测黑屏并返回实际分段和输出名。
- `POST /api/v1/tools/auto-video-split`：复用检测结果和命名规则，提交现有任务队列。
- 请求字段：`source_file`、可选 `output_directory`、`minimum_black_seconds`（默认 `null` 表示自动检测；API 仍接受 0.1–600 秒的手动过滤供旧调用使用）、`pixel_threshold`（0–1，默认 0.10）、`picture_threshold`（0–1，默认 0.95）、`sequence_start`（1–999999）、可选 `naming`。前端不发送手动时长。
- 响应新增 `detected_black_ranges`（检测到的黑屏）、`black_detection`（自动/手动模式、保留的短闪黑数量、分隔黑屏时长最小/最大值）；`black_ranges` 继续表示实际删除的黑屏。
- 同一源文件指纹与检测参数最多缓存 8 份检测结果。修改命名时无需再次解码；源文件大小、修改时间或身份变化会重新检测。
- 使用 FFmpeg `blackdetect` 得到分隔区间，取其补集作为导出范围。视频流时长优先于容器时长，避免尾部音频填充造成空画面。
- 通过准确输入寻址和重新编码在非关键帧处分割，保留画面尺寸和帧率，音频同步截取并转 AAC；没有音轨时输出无音轨视频。
- 遵循全局软件编解码设置；默认硬件优先，失败时独立回退。分段进度、实际编码器、失败信息和取消复用现有任务详情。
- 输出根目录默认是源视频所在目录，每次创建独立批次文件夹，内含视频、配置与检测快照、`manifest.json` 和 `manifest.csv`。CSV 记录起止秒数和序号。
- 导出前后校验源文件指纹；取消或失败清理未完成的 `.part.mp4`，保留已成功导出的片段。

## 验证

`tests/test_auto_video_split.py` 覆盖不指定时长的真实 FFmpeg 自动检测、混合长度分隔（0.5/2、1/3、10/7 秒）、短闪黑保留、手动 API 兼容、非关键帧切割的帧数和首尾画面、音轨有无、序号与积木名、重名、检测缓存失效、源文件变化、全黑/无分隔、API 和取消清理。前端布局测试覆盖工具入口、命名组件接入及无手动时长输入。

命名接口回归会禁止所有外部进程和检测调用，验证仍可只凭文件名完成；前端行为测试验证只调用命名接口、不操作分段结果或开始按钮，并丢弃规则变更前返回的过期命名结果。


## 2026-10-15 带文字黑屏漏检修复

真实文件 `通用-热菜-合规素材-美食混剪-ai美食混剪-lr合规闪购通用-dq-1015-21-40.mp4` 的分隔画面保留了顶部标识和左侧竖排合规文字。22 秒抽样帧的黑色像素比例为 97.1406%，未达到原先 98% 的阈值，因此返回 0 处黑屏、整条 1 段。

默认黑色画面比例调整为 95%，像素亮度阈值与自动时长检测逻辑保持原有设置；API 仍可显式指定比例。补充固定标识加竖排文字的真实 FFmpeg 回归样例，验证原 98% 能重现漏检、新默认值能识别；另验证带可见主体的暗色画面不会被误判为黑屏。
