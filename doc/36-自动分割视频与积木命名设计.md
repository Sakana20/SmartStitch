# 自动分割视频与积木命名

## 使用流程

工具台 → 自动分割视频 → 选择一个 MP4、MOV、M4V、MKV 或 WebM 视频 → 设置输出位置、起始序号或积木命名 → 自动检测并预览分段 → 开始分割。

默认自动检测，无需填写黑屏秒数，也不假定所有分隔黑屏都一样长。用 `blackdetect` 测量每处黑屏起止时间，支持 0.5、1、3、7、10 秒等混合长度；预览显示分隔黑屏实际时长范围和每处的起止、持续时间。像素亮度阈值为 0.10，黑色画面比例为 0.98。自动模式扫描至少 0.05 秒的黑屏，短于 0.3 秒的闪黑保留在片段内，防止瞬间闪黑引入额外切点；未使用的短黑屏也计入检测快照。片头和片尾的分隔黑屏去掉，不生成空片段。没有可用于分段的黑屏时预览提示并导出整条视频，全黑视频拒绝提交。

## 命名

关闭积木命名时，输出为 `01.mp4`、`02.mp4` 等，起始序号设为 21 则为 `21.mp4`、`22.mp4` 等。

开启后复用 `renderBuilderEditor`、`bindBuilderControls` 和后端 `derive_plan_naming` / `render_plan_filename`。源视频是 `pool_1`，文件名字段按 `|!|` 分隔。支持素材字段、可编辑文字、日期和序号块及拖动排序；序号取积木编辑器中的起点。每个片段使用同一个源视频文件名，序号随片段顺序增加。重名使用现有递增后缀，非法字段、非法文件名和序号溢出在提交前拒绝。日期按本次预览或提交时冻结。

## 检测与导出

- `POST /api/v1/tools/auto-video-split/preview`：检测黑屏并返回实际分段和输出名。
- `POST /api/v1/tools/auto-video-split`：复用检测结果和命名规则，提交现有任务队列。
- 请求字段：`source_file`、可选 `output_directory`、`minimum_black_seconds`（默认 `null` 表示自动检测；API 仍接受 0.1–600 秒的手动过滤供旧调用使用）、`pixel_threshold`（0–1，默认 0.10）、`picture_threshold`（0–1，默认 0.98）、`sequence_start`（1–999999）、可选 `naming`。前端不发送手动时长。
- 响应新增 `detected_black_ranges`（检测到的黑屏）、`black_detection`（自动/手动模式、保留的短闪黑数量、分隔黑屏时长最小/最大值）；`black_ranges` 继续表示实际删除的黑屏。
- 同一源文件指纹与检测参数最多缓存 8 份检测结果。修改命名时无需再次解码；源文件大小、修改时间或身份变化会重新检测。
- 使用 FFmpeg `blackdetect` 得到分隔区间，取其补集作为导出范围。视频流时长优先于容器时长，避免尾部音频填充造成空画面。
- 通过准确输入寻址和重新编码在非关键帧处分割，保留画面尺寸和帧率，音频同步截取并转 AAC；没有音轨时输出无音轨视频。
- 遵循全局软件编解码设置；默认硬件优先，失败时独立回退。分段进度、实际编码器、失败信息和取消复用现有任务详情。
- 输出根目录默认是源视频所在目录，每次创建独立批次文件夹，内含视频、配置与检测快照、`manifest.json` 和 `manifest.csv`。CSV 记录起止秒数和序号。
- 导出前后校验源文件指纹；取消或失败清理未完成的 `.part.mp4`，保留已成功导出的片段。

## 验证

`tests/test_auto_video_split.py` 覆盖不指定时长的真实 FFmpeg 自动检测、混合长度分隔（0.5/2、1/3、10/7 秒）、短闪黑保留、手动 API 兼容、非关键帧切割的帧数和首尾画面、音轨有无、序号与积木名、重名、检测缓存失效、源文件变化、全黑/无分隔、API 和取消清理。前端布局测试覆盖工具入口、命名组件接入及无手动时长输入。
