# 简单模式与高级模式设计

## 1. 目标

配置管理分为三个层级：

1. **简单模式**：默认入口，用大卡片展示业务含义，只开放常用设置。
2. **高级模式**：原“可视化配置”，保留素材目录、编码、扫描、响度和批处理等全部参数。
3. **YAML 专家模式**：直接编辑完整配置文本。

简单模式只修改用户可见字段，保存时以现有完整配置为基础合并修改，因此不会重置隐藏的高级参数。

## 2. 简单模式结构

简单模式采用大卡片和问答式标题，并收敛为四步。桌面端第一排将项目信息与风险提示语并列展示，各占一半宽度；拼接顺序与成片效果保持全宽。移动端自动恢复单列：

- 项目信息：项目名称、项目类型和目录健康状态。启用状态只在高级模式管理。
- 视频拼接顺序：先展示“每个启用视频库随机取一条 → 按列表顺序拼接 → 输出成片”的生成逻辑，再显示自动步骤编号、视频库名称、素材数量、实际文件夹名和“参与拼接”开关；支持拖拽、上下移动、添加和删除。单击文件夹名会使用 macOS Finder、Windows 资源管理器或 Linux 文件管理器打开对应目录。简单模式关闭开关时将视频库设为停用；高级模式继续保留“必需 / 可选 / 停用”的详细选择。
- 风险提示语图片：开关、识别状态、显示范围、复制受管目录位置和直接更换图片。
- 命名设置：通用项目独立使用第 04 张全宽卡片，简单模式展示启用开关、产品、利益点、可选序号起点和只读文件名预览。
- 输出设置：顺延为第 05 张卡片，通过大选项选择竖屏、横屏、方形，快速、推荐、高清画质，以及允许重复、尽量避免、完全不重复；同时保留音量均衡开关。

简单模式不直接展示源目录、视频库物理目录和输出路径等技术信息；这些内容仍可在高级模式查看和编辑。

## 3. 隐藏的高级字段

简单模式不显示但完整保留以下设置：

- 配置 ID、schema、稳定素材池 ID和原始 timeline。
- 扩展名、默认权重、图片持续时长和精确素材路径。
- 编码器、像素格式、CRF/VBR、码率、采样率、声道和 Faststart。
- LUFS、LRA、dBTP 等响度参数。
- 随机算法、种子、批处理限制和扫描过滤规则。
- 风险图精确坐标、缩放算法和透明度。
- 成片命名模板、素材类别范围、SmartStitch 切片后缀处理、文件名解析正则、日期格式、达人/日期合并规则和重名后缀。

通用项目的产品和利益点可同时出现在简单模式和高级模式，但必须绑定同一份结构化草稿。简单模式保存时不得重建命名配置对象，以免覆盖高级解析规则。完整界面规范见[《通用成片动态命名与素材元数据拼接设计》](./16-成片动态命名与素材元数据拼接设计.md)。

## 4. 风险提示语图片替换

受管项目可在简单模式直接选择 PNG、JPG、WEBP 或 BMP 图片，最大 20 MB。系统会：

1. 校验配置版本，避免覆盖其他窗口的新修改。
2. 使用 ffprobe 验证图片可读。
3. 将原风险图移动到 `.smartstitch/overlay-backups/`，不直接删除。
4. 把新图片放入项目的“风险提示语图片”目录。
5. 设置为必需叠图，并继续由扫描器按唯一图片规则识别。

通用模式只显示“整条视频”和“指定时间”；淘宝闪购继续支持主要内容和利益点部分。

## 5. 模式切换

- 每次打开配置管理都默认进入简单模式，不沿用上一次关闭时所在的高级或 YAML 模式。
- 从高级模式切到简单模式时，先收集未保存的高级表单内容，再基于同一份草稿渲染简单模式。
- 每个配置继续分别记住高级区域折叠状态和各编辑器滚动位置。
