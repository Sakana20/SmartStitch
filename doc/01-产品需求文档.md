# SmartStitch 产品需求文档

## 1. 背景与目标

系统既要使用已经按“引子、利益点、结尾”切分完成的素材，也要支持对原始长视频进行机器粗分析和人工断点审核。审核后的片段再进入现有素材组合流程，并与多个产品前贴、利益点排版图片和尾帧共同生成成片。

产品目标：

- 降低人工挑选、排列、叠图和导出的重复工作量。
- 确保每条成片都包含配置要求的完整要素。
- 允许对跑量片段提高权重，让其在当天任务中出现得更多。
- 用多个配置隔离不同投放场景，例如“淘宝闪购-星广”和“淘宝闪购-常规”。
- 生成过程可追踪、可复现、可暂停后定位失败原因。

## 2. 用户与典型场景

主要用户是本机视频素材运营人员。

典型流程：

1. 用户打开网页界面。
2. 选择“淘宝闪购-星广”等配置。
3. 程序扫描配置引用的素材目录并提示可用、缺失或异常素材。
4. 用户调整单个素材的启用状态和权重。
5. 用户填写本次生成数量、输出目录，可选填写随机种子。
6. 用户预览本批次的组合计划。
7. 用户启动任务并查看逐条进度、日志、成功与失败数量。
8. 用户在结果页打开输出目录，并查看每条成片的素材来源。

## 3. 成片组成

默认时间线如下：

```text
前贴（可配置必需/可选/禁用）
  ↓
引子（必需，抽取 1 个）
  ↓
利益点视频（必需，默认抽取 1 个）
  ↓
结尾（必需，抽取 1 个）
  ↓
尾帧（可配置必需/可选/禁用）

利益点图片：作为最高视觉图层，按配置的时间范围覆盖到上述时间线
```

第一版默认每个类别抽取一个文件，但数据结构应允许将来配置某类抽取多个素材。

### 3.1 必备约束

- 引子、利益点视频、结尾三个类别任何一个无有效素材时，禁止启动生成。
- 配置把前贴或尾帧设为“必需”时，对应素材为空也禁止启动。
- 利益点图片设为“必需”时，图片不存在、不可读或格式不支持时禁止启动。
- 同一条成片不得遗漏配置声明为必需的要素。

### 3.2 利益点图片

- 支持透明 PNG，第一版也可支持 JPG/WebP。
- 原图排版已完成，程序不负责重新排版文字或价格。
- 图片始终位于最高图层。
- 支持以下叠加范围：整条成片、主片段（不含前贴/尾帧）、仅利益点视频、自定义开始/结束时间。
- 支持原尺寸、等比缩放、适配画布和明确的 `x/y` 定位。
- PNG 透明区域必须正确保留。
- 一个配置只包含一张固定利益点图片；同一配置生成的所有成片使用同一张图片，不参与随机抽取。

## 4. 功能需求

### 4.1 配置管理

- 新建、复制、重命名、启用、停用和删除配置。
- 从带中文注释的 YAML 文件加载配置。
- 前端修改后保存配置，并在覆盖前保留历史版本或备份。
- 支持配置校验，错误必须指出字段和原因。
- 配置之间互不影响；每次任务保存所使用的配置快照。

### 4.2 素材扫描与管理

- 扫描配置指定目录中的视频或图片。
- 显示文件名、时长、分辨率、帧率、编码、音频规格、权重和启用状态。
- 自动忽略 `._*`、`.DS_Store`、隐藏文件和不支持的格式。
- 文件新增、删除或修改后可手动刷新。
- 缺失文件显示明确状态，不静默跳过必需素材。
- 路径包含中文、空格或外接硬盘卷名时必须正常工作。

### 4.3 权重管理

- 每个前贴、引子、利益点视频、结尾和尾帧都可设置独立权重；利益点图片为配置级固定图片，不设置权重。
- 权重为大于等于 0 的数；`0` 等价于不参与抽取，但保留在配置中。
- 前端显示相对概率。例如同组权重为 `6、3、1` 时显示约 `60%、30%、10%`。
- 支持批量启用/停用和恢复默认权重。
- 权重按素材类别分别归一化，不跨类别比较。

### 4.4 批量生成

- 设置生成数量。
- 设置输出目录、文件名前缀和冲突处理方式。
- 可选固定随机种子；相同配置快照、素材集合、数量和种子应生成相同组合计划。
- 启动前显示预计组合分布和素材使用次数。
- 支持并发数配置；默认保守值，避免 FFmpeg 同时运行过多拖慢电脑。
- 显示当前条目、总进度、耗时、成功、失败和取消状态。
- 单条失败不导致整批停止，可配置最大重试次数。
- 用户可取消尚未开始的任务；正在写入的文件应安全结束或删除 `.part` 临时文件。

### 4.5 结果与追踪

- 输出视频采用不会互相覆盖的文件名。
- 每批生成一份清单，记录成片使用的各素材、配置、随机种子、FFmpeg 版本、开始结束时间和结果。
- 可按批次查看结果和错误。
- 支持在系统文件管理器中定位输出视频。
- 每条成功视频应有对应的组合记录，便于回溯跑量素材。

### 4.6 时间线人工审核

系统先对原始视频做粗略分析并给出候选断点，用户在时间线审核台完成最终确认。

- 时间线编辑区采用类似 Adobe Premiere Pro 的纵向结构：现有片段轨道上方增加独立的时间标尺栏，显示自适应刻度、时间码标签和播放头手柄。
- 时间标尺栏与下方片段/断点轨道共享同一缩放比例、水平滚动位置和当前帧；播放头竖线从标尺手柄向下贯穿全部轨道。
- 视频播放器进度条仍可用于定位，但不再称为“上方时间轴”；播放器、时间标尺和片段轨道必须同步到同一个当前帧。
- 在时间标尺、播放头或轨道中拖动时，播放头横坐标必须紧跟鼠标横坐标，不使用 `4px/帧` 等人为减速映射；定位精度通过时间线缩放和最终帧取整保证。
- 默认关闭自动吸附。只有用户按住 `Shift` 拖动播放头、断点或新增切点时，才吸附到附近已有断点。
- `Shift` 松开后立即恢复无吸附的跟手拖动，不得继续锁定目标。
- 所有最终断点都以原视频帧序号保存；显示秒数仅用于辅助阅读，不作为权威编辑值。
- 机器候选点、人工新增点、人工调整点和人工确认点必须可区分，并保留原始机器分析依据。

## 5. 前端页面

第一版建议为桌面浏览器使用的响应式 Web 页面。

### 5.1 配置列表页

- 配置名称、状态、最后修改时间。
- 新建、复制、编辑、删除和导入配置。

### 5.2 配置编辑页

- 基础信息与输出规格。
- 前贴、引子、利益点视频、结尾、尾帧五个素材区。
- 利益点图片区。
- 每个素材均可启用/停用、设置权重并查看媒体信息。
- 保存前实时校验；路径可手输，也可由本地目录选择器选择。

### 5.3 创建任务页

- 选择配置、数量、输出目录、随机种子、并发数。
- 素材预检结果。
- 组合计划和预计分布预览。
- 开始生成按钮。

### 5.4 任务详情页

- 总进度和逐条状态。
- 实时日志摘要。
- 取消任务、重试失败项、打开输出目录。
- 查看并下载批次清单。

### 5.5 时间线审核页

- 视频播放器及其原生播放进度条。
- PR 式时间线编辑区：上层为时间标尺栏，下层为片段/断点轨道。
- 时间标尺根据当前缩放级别显示主刻度、次刻度和时间码；缩放或水平滚动时上下严格对齐。
- 播放头包含标尺栏上的手柄和贯穿下方轨道的竖线，视频播放和任意定位操作都同步更新它。
- 时间标尺、播放头和轨道支持鼠标跟手拖动，并保留逐帧按钮与键盘逐帧操作。
- 默认不吸附；按住 `Shift` 接近断点时显示吸附高亮、目标帧和时间码。
- 显示当前帧、时间码、片段数量和断点来源，并允许保存人工审核结果。

## 6. 非功能需求

- 运行环境：优先支持当前 macOS 本机，后续保留 Windows 兼容性。
- 后端：Python；媒体处理必须调用本机 FFmpeg/ffprobe。
- 前端与后端通过本机 HTTP API 通信，默认仅监听 `127.0.0.1`。
- 路径不拼接进 shell 字符串，必须用参数数组调用子进程，避免中文、空格和特殊字符问题。
- 配置和任务记录应使用 UTF-8。
- FFmpeg 命令、标准错误和退出码必须记录，但日志不得无限增长。
- 生成文件先写入 `.part.mp4`，成功后原子改名，防止误把半成品当成成片。
- 单条任务失败时保留可诊断信息，不保留损坏的正式文件。

## 7. 第一版范围外

- 自动生成利益点图片排版。
- 在线素材下载、云端渲染或多人协作。
- 自动判断“跑量”并修改权重。
- 基于大模型的语义段落分类、镜头内容去重或质量打分；画面转场和静音等规则化粗分析属于时间线审核范围。
- 剪映工程的生成和修改。
- 投放平台自动上传。

## 8. 核心验收标准

1. 在给定的中文和空格路径上能完成素材扫描。
2. 每条成功成片均包含一个引子、一个利益点视频和一个结尾。
3. 配置要求前贴、尾帧或利益点图片时，成功成片确实包含对应要素。
4. 权重为 `6、3、1`、生成 100 条时，计划分配接近 60、30、10；结果允许因去重规则作少量调整，但必须在清单中解释。
5. 固定随机种子重复预览时，组合计划完全一致。
6. 利益点透明 PNG 位于最高图层且透明通道正确。
7. 任一素材缺失或媒体参数异常时，界面给出具体文件和原因。
8. 任一单条 FFmpeg 失败后，批次继续处理其他条目，且没有伪装成成功文件的半成品。
9. 每条成片都能从批次清单追溯到所有输入素材和配置快照。
10. 时间标尺栏与片段轨道的刻度、断点、片段边界和贯穿式播放头在不同缩放与滚动位置下保持横向对齐。
11. 拖动时间标尺、播放头或轨道时，播放头紧跟鼠标，不出现人为减速、累计偏移或松手后跳变；视频画面和帧号同步更新。
12. 默认拖动经过断点时不吸附；按住 `Shift` 后进入吸附范围才高亮并落到目标断点，松开 `Shift` 后立即恢复跟手拖动。
13. 25、30、50、60 fps 恒定帧率视频中，播放头和断点保存后重载的帧序号不变。
