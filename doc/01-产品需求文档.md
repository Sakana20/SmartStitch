# SmartStitch 产品需求文档

## 1. 背景与目标

系统既要使用已经按“引子、利益点、结尾”切分完成的素材，也要支持对原始长视频进行机器粗分析和人工断点审核。审核后的片段再进入现有素材组合流程，并与多个产品前贴、利益点排版图片和尾帧共同生成成片。

产品目标：

- 降低人工挑选、排列、叠图和导出的重复工作量。
- 确保每条成片都包含配置要求的完整要素。
- 允许对跑量片段提高权重，让其在当天任务中出现得更多。
- 用多个配置隔离不同投放场景，例如“淘宝闪购-星广”和“淘宝闪购-常规”。
- 用统一的视频库目录承接原始视频、批量切片、分类素材、成片和清单，避免每次人工建目录。
- 生成过程可追踪、可复现、可暂停后定位失败原因。

## 2. 用户与典型场景

主要用户是本机视频素材运营人员。

典型流程：

1. 用户打开网页界面。
2. 首次使用时，用户新建视频库并选择它在本机或外接盘上的保存位置；系统创建标准目录和配置。
3. 选择“淘宝闪购-星广”等配置。
4. 程序扫描配置引用的素材目录并提示可用、缺失或异常素材。
5. 用户调整单个素材的启用状态和权重。
6. 用户填写本次生成数量、输出目录，可选填写随机种子。
7. 用户预览本批次的组合计划。
8. 用户启动任务并查看逐条进度、日志、成功与失败数量。
9. 用户在结果页打开输出目录，并查看每条成片的素材来源。

## 3. 成片组成

默认时间线如下：

```text
前贴（可配置必需/可选/禁用）
  ↓
引子（必需，抽取 1 个）
  ↓
利益点 1（必需，抽取 1 个）
  ↓
利益点 2（可配置，抽取 1 个）
  ↓
利益点 3（可配置，抽取 1 个）
  ↓
结尾（必需，抽取 1 个）
  ↓
尾帧（可配置必需/可选/禁用）

风险提示语图片：作为最高视觉图层，按配置的时间范围覆盖到上述时间线
```

每个利益点段是独立素材池，从本段候选中抽取一个文件。利益点段可在配置中增加、删除和排序，以支持同一条成片在利益点之间切换人物。具体协议见[《多段利益点配置设计》](./07-多段利益点配置设计.md)。

### 3.1 必备约束

- 引子、结尾或任一配置为必需的利益点段无有效素材时，禁止启动生成；整条时间线至少保留一个利益点段。
- 配置把前贴或尾帧设为“必需”时，对应素材为空也禁止启动。
- 风险提示语图片设为“必需”时，图片不存在、不可读或格式不支持时禁止启动。
- 同一条成片不得遗漏配置声明为必需的要素。

### 3.2 风险提示语图片

- 支持透明 PNG，第一版也可支持 JPG/WebP。
- 原图排版已完成，程序不负责重新排版文字或价格。
- 图片始终位于最高图层。
- 支持以下叠加范围：整条成片、主片段（不含前贴/尾帧）、全部利益点段、自定义开始/结束时间。
- 支持原尺寸、等比缩放、适配画布和明确的 `x/y` 定位。
- PNG 透明区域必须正确保留。
- 一个配置只包含一张固定风险提示语图片；同一配置生成的所有成片使用同一张图片，不参与随机抽取。

## 4. 功能需求

### 4.1 配置管理

- 新建、复制、重命名、启用、停用和删除配置。
- 从带中文注释的 YAML 文件加载配置。
- 前端修改后保存配置，并在覆盖前保留历史版本或备份。
- 支持配置校验，错误必须指出字段和原因。
- 配置之间互不影响；每次任务保存所使用的配置快照。
- 新建受管视频库时必须询问用户保存位置，一次创建标准目录、库元数据和可直接扫描的配置。
- 利益点段支持添加、删除和排序；受管库新建利益点时自动创建对应文件夹，删除只修改配置，不删除本地素材文件。
- 旧版单一 `benefit_video` 配置可无损迁移为第一个利益点段。

### 4.2 素材扫描与管理

- 扫描配置指定目录中的视频或图片。
- 显示文件名、文件日期、时长、分辨率、帧率、编码、音频规格、权重和启用状态。文件日期取扫描结果中的文件系统修改时间，不定义为上传或首次入库时间。
- 自动忽略 `._*`、`.DS_Store`、隐藏文件和不支持的格式。
- 文件新增、删除或修改后可手动刷新。
- 缺失文件显示明确状态，不静默跳过必需素材。
- 路径包含中文、空格或外接硬盘卷名时必须正常工作。
- 素材权重表支持按素材名称、文件日期、权重、组内占比和状态升序或降序排列；排序只改变当前界面的展示顺序，不修改扫描顺序、配置内容或组合计划。
- 素材权重表提供独立于“启用”的行选择框、当前素材库全选、Shift 连续选择和清除选择。选择状态只用于界面操作，不等价于启用、停用或保存权重。
- 本阶段不提供日期区间、标签、关键字等条件筛选；表头入口只承担升序和降序排序。

### 4.3 权重管理

- 每个前贴、引子、各利益点段、结尾和尾帧素材都可设置独立权重；风险提示语图片为配置级固定图片，不设置权重。
- 权重为大于等于 0 的数；`0` 等价于不参与抽取，但保留在配置中。
- 前端显示相对概率。例如同组权重为 `6、3、1` 时显示约 `60%、30%、10%`。
- 支持批量启用/停用和恢复默认权重。
- 权重按素材类别分别归一化，不跨类别比较。

### 4.4 批量生成

- 设置生成数量。
- 设置输出目录、文件名前缀和冲突处理方式。
- 可选固定随机种子；相同配置快照、素材集合、数量和种子应生成相同组合计划。
- 启动前显示预计组合分布和素材使用次数。
- 支持并发数配置；默认保守值，避免 FFmpeg 同时运行过多拖慢电脑。
- 显示当前条目、总进度、耗时、成功、失败和取消状态。
- 单条失败不导致整批停止，可配置最大重试次数。
- 用户可取消尚未开始的任务；正在写入的文件应安全结束或删除 `.part` 临时文件。

### 4.5 结果与追踪

- 输出视频采用不会互相覆盖的文件名。
- 每批生成一份清单，记录成片使用的各素材、配置、随机种子、FFmpeg 版本、开始结束时间和结果。
- 可按批次查看结果和错误。
- 支持在系统文件管理器中定位输出视频。
- 每条成功视频应有对应的组合记录，便于回溯跑量素材。

### 4.6 时间线人工审核

系统先对原始视频做粗略分析并给出候选断点，用户在时间线审核台完成最终确认。

- 时间线编辑区采用类似 Adobe Premiere Pro 的纵向结构：现有片段轨道上方增加独立的时间标尺栏，显示自适应刻度、时间码标签和播放头手柄。
- 时间标尺栏与下方片段/断点轨道共享同一缩放比例、水平滚动位置和当前帧；播放头竖线从标尺手柄向下贯穿全部轨道。
- 视频播放器进度条仍可用于定位，但不再称为“上方时间轴”；播放器、时间标尺和片段轨道必须同步到同一个当前帧。
- 只有时间标尺栏可以定位和拖动播放头；播放头横坐标必须紧跟鼠标横坐标，不使用 `4px/帧` 等人为减速映射。下方片段轨道的空白区域不响应播放定位，只允许拖动轨道中的断点。
- 用户通过时间标尺移动播放头时应立即暂停视频；操作结束后保持暂停，即使操作前视频正在播放也不得自动恢复。
- 默认关闭自动吸附。用户按住 `Shift` 拖动时间标尺时可吸附到附近已有断点；按住 `Shift` 拖动断点时，还可吸附到当前播放头竖线所在帧，且播放头本身不移动。
- `Shift` 松开后立即恢复无吸附的跟手拖动，不得继续锁定目标。
- 时间线页面激活时，除文本编辑控件外，全局按空格均切换视频播放/暂停；快捷键必须在捕获阶段阻止页面滚动和其他控件的空格默认行为。
- 非文本编辑状态下，`Command + Z` 撤销上一次断点或待切片编辑，`Command + Shift + Z` 重做；新的编辑会清空重做栈，切换视频或成功提交后清空全部历史。
- 鼠标悬停在时间线编辑区并按住 macOS `Option` 滚动滚轮时，以鼠标所在时间点为锚点缩放时间线；未按 `Option` 时保留时间线原有滚动行为。
- 所有最终断点都以原视频帧序号保存；显示秒数仅用于辅助阅读，不作为权威编辑值。
- 播放器连续时间回退到帧号时必须按当前帧区间向下取整，不得因四舍五入使播放头提前一帧；手动定位不得设置帧级 seek 死区，并应在目标帧区间内部取样，避免浏览器在精确边界显示前一帧。
- 机器候选点、人工新增点、人工调整点和人工确认点必须可区分，并保留原始机器分析依据。

### 4.7 标准视频库与批量入库

- 新建视频库的向导必须显示库名称、用户选择的保存位置、最终绝对路径和将创建的目录树。
- 标准库包含原始视频、前贴、引子、独立利益点池、结尾、尾帧、未归类切片、风险提示语图片、成片输出和工作记录目录。
- 批量切片在提交前选择目标库和素材类别；未标注类别的片段只能进入“未归类”，不得猜测为某个利益点。
- 每个切片任务输出可追溯清单，且不默认移动或删除原视频。
- 详细目录、元数据、异常恢复与 API 见[《标准视频库设计》](./08-标准视频库设计.md)。
- 时间线下方以“片段列表”取代“断点列表”和独立批量区；默认列表为空，连续点击时间轴区间可累计标记多个片段，并逐条选择前贴、引子、动态利益点、结尾、尾帧或未归类。
- 右上角只保留“切割并入库”：点击后先保存最新断点审核版本，再只把列表中的片段子集交给后端 FFmpeg。详见[《片段审核与分类切片设计》](./09-片段审核与分类切片设计.md)。

## 5. 前端页面

第一版建议为桌面浏览器使用的响应式 Web 页面。

### 5.1 配置列表页

- 配置名称、状态、最后修改时间、视频库路径和布局健康状态。
- 新建视频库、复制、编辑、删除和导入配置；新建向导内必须先选择保存位置。

### 5.2 配置编辑页

- 基础信息与输出规格。
- 前贴、引子、可增删排序的利益点段列表、结尾、尾帧素材区。
- 风险提示语图片区。
- 每个素材均可启用/停用、设置权重并查看媒体信息。
- 保存前实时校验；路径可手输，也可由本地目录选择器选择。

### 5.3 素材权重页

- 按视频库标签页展示当前参与生成的候选素材。
- 展示文件日期，并对素材名称、文件日期、权重、组内占比和状态提供升降序排序。
- 第一列为素材选择复选框，第二列为“已启用 / 已停用”状态按钮，两者必须在视觉和行为上保持独立；启用状态不得再使用复选框，以免与多选含义混淆。
- 支持表头全选当前素材库；先选择一行后按住 Shift 再选择另一行，可连续选择两行之间的素材。
- 支持在表格非控件区域按住鼠标左键拖拽框选。拖拽时显示符合当前主题色的浅绿色半透明矩形，与矩形相交的素材行进入选择；从选择框、状态按钮、标签或权重输入框开始拖动时不得触发框选。
- 框选模式由拖拽起点决定：从未选中的素材行开始拖拽时，本次矩形命中的素材全部进入选择，原有选择保持不变；从已选中的素材行开始拖拽时，本次命中的素材全部取消选择。拖拽方向不影响结果，未被本次矩形命中的素材始终保持原状态。连续两次从同一素材起点框选同一批素材，应恢复到框选前状态。
- “已停用”按钮使用红色警示状态，“已启用”按钮继续使用绿色状态，保证两者可以一眼区分。
- 排序、切换素材库或重新渲染表格时，权重、标签和启用状态仍按素材 ID 回写，不能因行位置变化写到其他素材。
- 当前版本不包含 Excel 式条件筛选菜单；未激活的可排序表头显示双向提示，激活后明确显示当前升序或降序方向。
- “权重”表头右侧显示圆形问号，鼠标悬停或键盘聚焦时展示权重说明。说明至少包含：权重是同库相对比例而非固定次数、权重 0 和停用均不参与拼接、不同素材库分别计算，以及 `6 / 3 / 1` 在生成 10 条时通常对应约 `6 / 3 / 1` 次的示例。问号不触发表头排序。
- 素材权重页不在表格上方提供额外的批量权重输入栏。选中多条素材后，在任意一条已选素材自身的权重输入框填写大于等于 0 的数值并按回车，当前素材库内全部已选素材立即更新为该权重并重算占比；在未选素材的权重框按回车时只修改该素材。
- 点击已选素材行的“已启用 / 已停用”按钮时，以被点击素材切换后的状态为目标，批量更新当前素材库的全部已选素材；点击未选素材行的按钮时仍只更新该素材。
- 权重、启用状态和标签的修改均为页面草稿，不自动写入配置。页面右上角保留唯一的“保存权重”按钮，用户确认后统一提交。
- 进入素材权重页时必须获取与配置管理相同的配置级独占编辑锁，并持续续租；不能获取锁时页面保持只读。离开页面时若存在未保存修改，先询问是否放弃；确认离开后释放锁。保存请求必须携带当前独占锁与进入页面时的配置版本，不得在保存瞬间临时抢锁。
- 配置管理和素材权重页的单次独占编辑最长均为 5 分钟。该上限从成功获取编辑锁时开始计算，保存、鼠标键盘操作和正常续租均不得重置，且独立于原有租约有效期与续租机制。素材权重达到上限后主动释放锁、切换为只读并保留当前页面草稿；配置管理达到上限后主动释放锁、关闭编辑弹窗并放弃未保存的配置草稿。两者都必须明确弹窗提示，用户重新进入后才能再次获取编辑权。

### 5.4 创建任务页

- 选择配置、数量、输出目录、随机种子、并发数。
- 素材预检结果。
- 组合计划和预计分布预览。
- 开始生成按钮。

### 5.5 任务详情页

- 总进度和逐条状态。
- 实时日志摘要。
- 取消任务、重试失败项、打开输出目录。
- 查看并下载批次清单。

### 5.5 时间线审核页

- 视频播放器及其原生播放进度条。
- PR 式时间线编辑区：上层为时间标尺栏，下层为片段/断点轨道。
- 时间标尺根据当前缩放级别显示主刻度、次刻度和时间码；缩放或水平滚动时上下严格对齐。
- 播放头包含标尺栏上的手柄和贯穿下方轨道的竖线，视频播放和任意定位操作都同步更新它。
- 时间标尺支持播放头跟手拖动；下方轨道仅支持断点拖动，其空白区域不改变播放位置；同时保留逐帧按钮与键盘逐帧操作。
- 时间线页全局支持空格播放/暂停；鼠标悬停时间线时支持 `Option` + 滚轮缩放。
- 默认不吸附；按住 `Shift` 接近已有断点或播放头时显示吸附引导、目标帧和时间码。
- 显示当前帧、时间码、片段数量和断点来源；片段列表支持批量标记、分类和移除，右上角“切割并入库”直接保存审核并执行。

## 6. 非功能需求

- 运行环境：优先支持当前 macOS 本机，后续保留 Windows 兼容性。
- 后端：Python；媒体处理必须调用本机 FFmpeg/ffprobe。
- 前端与后端通过本机 HTTP API 通信，默认仅监听 `127.0.0.1`。
- 路径不拼接进 shell 字符串，必须用参数数组调用子进程，避免中文、空格和特殊字符问题。
- 配置和任务记录应使用 UTF-8。
- FFmpeg 命令、标准错误和退出码必须记录，但日志不得无限增长。
- 生成文件先写入 `.part.mp4`，成功后原子改名，防止误把半成品当成成片。
- 单条任务失败时保留可诊断信息，不保留损坏的正式文件。

## 7. 第一版范围外

- 自动生成风险提示语图片排版。
- 在线素材下载、云端渲染或多人协作。
- 自动判断“跑量”并修改权重。
- 基于大模型的语义段落分类、镜头内容去重或质量打分；画面转场和静音等规则化粗分析属于时间线审核范围。
- 剪映工程的生成和修改。
- 投放平台自动上传。

## 8. 核心验收标准

1. 在给定的中文和空格路径上能完成素材扫描。
2. 每条成功成片均包含一个引子、一个结尾，并按配置顺序包含每个必需的利益点段。
3. 配置要求前贴、尾帧或风险提示语图片时，成功成片确实包含对应要素。
4. 权重为 `6、3、1`、生成 100 条时，计划分配接近 60、30、10；结果允许因去重规则作少量调整，但必须在清单中解释。
5. 固定随机种子重复预览时，组合计划完全一致。
6. 利益点透明 PNG 位于最高图层且透明通道正确。
7. 任一素材缺失或媒体参数异常时，界面给出具体文件和原因。
8. 任一单条 FFmpeg 失败后，批次继续处理其他条目，且没有伪装成成功文件的半成品。
9. 每条成片都能从批次清单追溯到所有输入素材和配置快照。
10. 时间标尺栏与片段轨道的刻度、断点、片段边界和贯穿式播放头在不同缩放与滚动位置下保持横向对齐。
11. 只有拖动时间标尺才改变播放头，且播放头紧跟鼠标，不出现人为减速、累计偏移或松手后跳变；拖动下方轨道空白处不改变播放位置，断点本身仍可拖动。
12. 默认拖动不吸附；按住 `Shift` 后进入吸附范围才落到已有断点或播放头所在帧，松开 `Shift` 后立即恢复跟手拖动。断点吸附到播放头时，播放头竖线与视频帧保持不变。
13. 25、30、50、60 fps 恒定帧率视频中，播放头和断点保存后重载的帧序号不变。
14. 增加或删除利益点段后，预览、渲染和清单中的段数与顺序均与配置一致，且删除配置不会删除原素材。
15. 新建视频库在用户未选择保存位置时无法提交，成功后标准目录完整且配置路径可直接扫描。
16. 受管视频库添加利益点后，新素材组、时间线与对应目录同时成功；删除利益点不删除其目录和视频。
17. 批量切片入库后，任一切片都可从清单追溯到原视频和权威帧区间。
