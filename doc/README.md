# SmartStitch 文档索引

SmartStitch 是一个本地运行的 Python 前后端工具，用 FFmpeg 将已处理好的短视频素材按配置随机组合，并叠加可变的风险提示语图片。

本目录用于维护产品、交互、数据和技术设计，内容应与当前业务代码及后续开发计划保持同步。

## 已确认的实际素材

主素材目录：

```text
/Volumes/Elements SE/<业务素材目录>/饿了么整理/素材/星广一口价/25元/分割后
├── 引子
│   ├── 1.mp4
│   └── 2.mp4
├── 利益点
│   ├── 1.mp4
│   ├── 2.mp4
│   └── 美食-lr闪购-dq-日期-序号.mp4
└── 结尾
    ├── 1.mp4
    ├── 2.mp4
    └── 3.mp4
```

前贴目录：

```text
/Volumes/Elements SE/<业务素材目录>/饿了么整理/素材/前贴/260908同步/0.1
```

已抽样检测到的主素材规格为 720×1280、30fps、H.264 视频、AAC 48kHz 双声道音频。前贴抽样同样为 720×1280、30fps、H.264 + AAC。程序仍必须逐个执行 `ffprobe`，不能假定所有文件完全一致。

## 当前设计基线

- 默认成片顺序：前贴 → 引子 → 利益点 1 → 利益点 2 → 利益点 3 → 结尾 → 尾帧；利益点段数量由配置增删。
- 每条成片必须包含引子、结尾和至少一个利益点段；前贴、风险提示语图片和尾帧是否必需由配置控制。
- 各视频片段可单独设置权重；权重只表示相对抽取概率。
- 一个“配置”代表一套独立的素材路径、风险提示语图片、前贴、尾帧、输出参数与抽取规则。
- 每个配置固定唯一一张风险提示语图片，不参与随机抽取；图片位于最终视频的最高视觉图层，叠加时段和位置可配置。
- 默认按“配额分配后洗牌”实现每日权重，使小批量输出也更接近期望比例。
- 忽略以 `._` 开头的 macOS 伴生文件、隐藏文件、临时文件和不支持的扩展名。
- 新建受管视频库必须先由用户选择保存位置；标准目录一次创建，新建利益点时自动创建对应素材文件夹。
