# 工具台竖改横设计

状态：首版已实现（2026-09-28）；真实 FFmpeg 样片及自动化交互回归已验证，正式桌面包人工验收待做。

## 1. 需求与画面规则

按[工具台横改竖设计](./30-工具台横改竖设计.md)提供反向转换，工具稳定 ID 为 `portrait-to-landscape`，排在横改竖之后。普通用户和管理员均可使用，不依赖项目配置。

用户选择文件夹，批量将竖屏视频转换为 16:9 横屏。默认 1280×720，可选 1920×1080。清晰前景按源显示比例完整装入画布并居中，不裁切、不拉伸；背景来自同一次解码分出的同帧视频，等比放大覆盖画布、居中裁切并高斯模糊，补满左右空白。前景取偶数尺寸；9:16 输入在 720p 下约为 404×720，1080p 下约为 608×1080。

模糊强度按画布短边计算：720p 使用 sigma=20、steps=2；1080p 使用 sigma=30。保留原播放速度、帧时间戳和第一条音轨，音频转 AAC；无声输入不生成静音轨。先应用旋转元数据及像素比例，再按显示高度大于显示宽度判断竖屏。横屏及正方形标记“跳过：不是竖屏视频”。HDR、隔行、多视频轨、损坏素材等检查规则与横改竖一致。

## 2. 面板与文件约定

表单顺序：输出分辨率双按钮 → 源视频文件夹 → 输出文件夹（可选）→ 读取视频 / 开始竖改横 → 文件列表。

- 两个分辨率按钮分别为 **720p · 1280×720**、**1080p · 1920×1080**；默认 720p，互斥高亮，使用 `aria-pressed`，支持键盘操作。
- 读取只列出第一层 MP4 / MOV / M4V / MKV 文件，不调用 ffprobe，不读取媒体元信息；文件顺序、隐藏文件及临时文件排除规则沿用横改竖。
- 默认输出目录为 `<源文件夹>/竖改横`，读取时不创建；自选目录可与源目录相同。
- 文件名为 `<源文件名不含扩展名>_竖改横.mp4`，同名追加 `_2`、`_3`，原素材和已有结果均保留。扫描排除 `_竖改横` 及数字后缀结果。
- 修改任一目录或切换分辨率，使旧清单失效；重复点击当前规格保留清单。离开面板或修改参数后，旧读取响应不能更新面板。
- 提交只接受后端保存的 `preview_id`，核对文件名清单后启动；清单新增、删除或改名提示重新读取，成功提交的预检不能再次使用。

## 3. 执行与任务记录

与横改竖共用逐文件探测、方向判断、尺寸计算、滤镜、编码、输出校验、发布、进度和取消管线。每种方向分别维护预检、活动批次及任务表，不能跨方向提交预检 ID。同一种方向一次执行一个批次。

编码优先使用可用的 Apple Silicon VideoToolbox，硬编失败后清理临时文件并软编重试一次，同批后续文件直接使用 libx264。任务保存实际编码器和回退原因。保留时间戳，输出 H.264 / yuv420p / AAC / faststart MP4。发布前验证尺寸、时长、音轨，以及适用的基础帧率和已有帧数；独占预留输出名，避免覆盖并发生成的文件。

任务记录类型显示“竖改横”，详情复用横改竖和切片的进度、统计卡片、紧凑信息栏及逐条结果样式，显示该批次的实际宽高与 16:9 比例。刷新、返回、切换页面后可查看；支持取消当前及剩余文件、删除已结束记录。删除记录保留结果。桌面退出将任务纳入计数及终止清理，重启后未结束批次标记中断，不自动恢复。

## 4. 接口及实现位置

接口沿用登录会话校验。

| 接口 | 用途 |
| --- | --- |
| `POST /api/v1/tools/portrait-to-landscape/preview` | 接收 `source_directory`、可选 `output_directory`、`resolution`（720p / 1080p），返回清单及实际输出宽高 |
| `POST /api/v1/tools/portrait-to-landscape` | 接收 `preview_id`，提交批次 |
| `GET /api/v1/tools/portrait-to-landscape/jobs` | 查询历史及活动批次 |
| `GET /api/v1/tools/portrait-to-landscape/{id}` | 查询详情 |
| `POST /api/v1/tools/portrait-to-landscape/{id}/cancel` | 取消任务 |
| `DELETE /api/v1/tools/portrait-to-landscape/{id}` | 删除已结束记录 |

- `smartstitch/portrait_to_landscape.py`：定义竖改横方向、输出分辨率、命名及独立 `landscape_jobs` 表，继承共用转换管理器。
- `smartstitch/landscape_to_portrait.py`：方向、任务表、分辨率和文件后缀改为可复用策略；模糊按画布短边计算，横改竖原行为保留。
- `smartstitch/api.py`、`database.py`、`desktop.py`：接口、持久化和生命周期接入。
- `frontend/app.js`：开放卡片，共用面板、任务详情，接入竖改横历史、轮询和路由；`index.html` 更新缓存版本。

## 5. 验证范围

真实 FFmpeg 样片覆盖 720p / 1080p 尺寸、清晰完整的居中前景、左右模糊背景、有声与无声输入、帧率、中文空格路径、同名不同扩展名、已有目标避让、混合方向和损坏文件、预检消费、两个方向的任务隔离、历史恢复及删除保留输出。

交互回归同时运行两种方向，覆盖分辨率切换、高亮、预检失效、迟到响应丢弃、提交、任务记录路由及详情规格；横改竖原有后端回归用于验证共用管线的旋转、像素比例、VFR、硬编回退、取消和中断等行为。
